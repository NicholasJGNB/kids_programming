# 🤖 给孩子的编程启蒙

一个为 **6 岁半左右** 孩子准备的编程启蒙小项目。核心思路是：**先用游戏建立"编程的思维"，再一步步过渡到能动起来的实体机器人。**

---

## 🎮 一、现在就能玩：《小机器人去充电》

打开 [`index.html`](index.html) 就能玩，**不用安装任何东西**，电脑、平板、手机的浏览器都可以。竖屏、横屏都适配：手机横屏时会自动变成"左边大地图、右边按钮"的两栏布局，iPad 横竖屏也都好用。

### 玩法
孩子用十字方向键给机器人"下命令"：

| 按钮 | 作用 |
|------|------|
| ⬆ 上 | 向上走一格 |
| ⬇ 下 | 向下走一格 |
| ⬅ 左 | 向左走一格 |
| ➡ 右 | 向右走一格 |

把命令一个个排好，按 **▶ 出发！**，机器人就会照着命令走，目标是走到 🔋 电池那里充电。撞墙或走出地图会失败，可以 **↩ 撤回** 或 **🗑 清空** 重新来。

还有一个 **🔁 重复** 按钮，像积木一样工作：点 🔁 会出现一个紫色的"圈"，**接下来点的方向都会掉进这个圈里**；再点一次 🔁（按钮会变成「✓ 结束圈」）就收口。圈里的动作会**整组重复 N 次**（点圈上的 −/＋ 调次数）。比如把 ➡⬆ 放进一个 ×2 的圈，机器人就会走「➡⬆➡⬆」——这是孩子第一次接触真正的编程概念「循环」。

一共 **18 关**，从"直直走两步"一路到"8×8 大迷宫"，难度平滑上升。一部分关卡地上有**宝贝**（⭐💎🍎🍓🎁🍪🍰…会变换花样），要**先把宝贝都捡完、再走到电池**才能过关；挡路的**障碍**也丰富多样（🪨💩🌵🔥🧱🌳…），让每一关看起来都不一样。点状态栏右侧的 **🗺 选关** 按钮，会弹出关卡网格，可以随时跳到任意一关，通关过的关卡会标上 ⭐。

关卡分四组：
- **第 1~4 关**：认识上下左右、第一次捡宝贝
- **第 5~8 关**：开始有障碍要绕、穿门洞
- **第 9~12 关**：S 形迷宫、绕路捡多个宝贝
- **第 13~18 关**：7×7、8×8 大迷宫，越来越有挑战

#### 🏗 自己造一关（关卡玩不完）
在 🗺 选关 浮层里点 **「🏗 自己造一关」**，就进入搭建模式：用 🪨障碍 / ⭐宝贝 / 🤖起点 / 🔋电池 / 🧹擦掉 这几个画笔，点格子就能画出自己的地图，还能 **📐 换大小**（5×5～8×8）。画好点 **▶ 开始玩** 就能挑战自己设计的关（系统会先帮你检查"能不能走通"）。

> 💡 玩法建议：让孩子和家长**互相出题**——你摆一张地图给孩子闯，孩子也摆一张"为难"你。出题时要想"这样能不能走通"，其实是更高级的逆向思维训练。

### 它在偷偷教什么？
- **顺序（Sequence）**：命令的先后顺序决定结果 —— 这是所有编程的基础。
- **循环（Loop）**：用 🔁 把重复的动作"打包"，少写很多步 —— 这是真正的编程核心概念之一。
- **方向感**：用上下左右规划路线，锻炼空间感。
- **试错与调试（Debug）**：走错了不要紧，撤回、修改、再试一次。这正是程序员每天在做的事。

> 💡 这个游戏的核心是"把一串命令排好，让机器人照着走"，和后面要玩的实体编程机器人（如 Bee-Bot、micro:bit 小车）是同一个思路。**孩子在屏幕上学会的"先规划、再执行"，换成真机器人一样用得上。**

## 🗺️ 二、从软件到硬件的成长路线

不用一次买齐，按孩子的兴趣和专注力一步步来即可。

### 第 0 阶段（现在）：屏幕上的"指挥游戏"
- 玩本项目的《小机器人去充电》。
- 也推荐 **ScratchJr**（iPad / 安卓平板，免费）：用积木块拼出小动画，5–7 岁绝配。
- **目标**：理解"我下命令 → 它照做"，建立顺序和因果思维。

### 第 1 阶段：不插电也能玩（培养逻辑，零成本）
- 在地板上用胶带贴出格子，做一个真人版"机器人游戏"：家长当机器人，孩子用"前进 / 左转 / 右转"卡片指挥你走到目标。
- 经典桌游推荐：**《Robot Turtles》**、**《Code & Go 机器鼠》**。
- **目标**：把屏幕上的概念搬到现实，孩子会更有掌控感。

### 第 2 阶段：第一台实体编程机器人（强烈推荐的"软件→硬件"跳板）
这一步最关键，按性价比/年龄推荐：

| 推荐 | 适合年龄 | 大概价位 | 特点 |
|------|---------|---------|------|
| **Bee-Bot 小蜜蜂机器人** | 4–7 岁 | ¥300–500 | 按机身上的前进/转弯按钮编程，**和本游戏几乎一模一样**，无屏幕、最适合作为第一台 |
| **Matatalab 玛塔编程套装** | 4–9 岁 | ¥600–1200 | 用实体"命令卡"在地图上拼程序，不用屏幕，可玩很久 |
| **micro:bit + 智能小车** | 7 岁+ | ¥200–400 | 用 [MakeCode](https://makecode.microbit.org) 积木编程，能扩展灯光/传感器，**能玩到中学**，性价比极高 |
| **LEGO® SPIKE / WeDo** | 7 岁+ | ¥1500+ | 拼搭 + 编程结合，喜欢乐高的孩子首选 |

**给六岁半孩子的建议**：先入手 **Bee-Bot**（无缝衔接本游戏、零挫败感），等孩子能稳定"规划三四步以上"，再上 **micro:bit 小车**（可玩好多年）。

> 🚗 **想直接上 micro:bit 小车？** 看这份手把手图文教程 👉 **[《micro:bit 小车上手教程》](../microbit-小车教程.md)**
> ——含采购清单、第一个程序、让小车"走方格"的完整步骤，买回来当天就能跟着做。

### 第 3 阶段：自己写程序控制硬件
- 用 **Scratch**（图形化）或 **MakeCode** 给 micro:bit 编程，点亮灯、读温度、控制小车。
- 再往后可接触 **Python**（micro:bit 支持 MicroPython）。
- **目标**：从"用别人做好的命令"到"自己创造命令"。

## 👨‍👩‍👧 三、给家长的几个小建议

1. **每次 10–20 分钟就好**。这个年龄注意力有限，玩得开心、意犹未尽最好。
2. **多陪玩、少纠正**。让孩子自己试错，撞墙了一起笑一笑再想办法。
3. **多问"接下来该怎么走？"**，引导孩子先在脑子里规划，再按按钮。
4. **重在思维，不在术语**。不用教"循环""变量"这些词，玩到了自然会懂。
5. **离开屏幕也能玩**。第 1 阶段的"真人机器人游戏"特别能锻炼逻辑，还增进亲子互动。
